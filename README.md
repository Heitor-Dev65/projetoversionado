# Sistema de Gerenciamento de Eventos Acadêmicos

##  Descrição do Projeto
Aplicação web desenvolvida para gerenciar eventos acadêmicos, permitindo o cadastro de novas atividades e a consulta rápida das informações sobre os eventos disponíveis.

##  Funcionalidades do Sistema
* **Cadastro de Eventos:**
  * Nome do evento;
  * Descrição;
  * Data e horário;
  * Localização;
  * Responsável;
  * Quantidade de vagas.
* **Consulta de Eventos:**
  * Listagem dos eventos cadastrados na plataforma.
